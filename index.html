Como emitir um certificado Let’s Encrypt com DNS externo?

Crie primeiro o registro _acme-challenge como CNAME para <domínio>.letsencrypt.azion.com. Só depois solicite o certificado: a emissão é assíncrona e passa de pending para active.

Projetos

O que eu construo quando ninguém pediu, direto do GitHub.

Agente ChatOps para a Azion

TypeScript

Pedidos em português viram um plano de execução revisável. Só depois da aprovação humana o agente executa contra a API v4 da Azion, por uma fila assíncrona.

  • Planner híbrido, por regras ou por LLM, gera um plano em JSON antes de qualquer execução.
  • Redis Streams com status em tempo real e histórico persistido em SQLite.
  • Importa DNS da Cloudflare, do Route53 e de zone files RFC 1035.
  • Migra domínios proxied com firewall, WAF, workload e certificado Let’s Encrypt via DNS-01.
  • Todo recurso nasce desativado até aprovação explícita.

TypeScript, Next.js, MCP, Redis Streams, SQLite, Azion API v4

Impact Study Generator

JavaScript

Gera o relatório executivo de antes e depois de uma migração de CDN a partir de dois exports do WebPageTest. Os números saem do código; a IA só escreve a prosa, e cada frase é conferida contra os dados.

  • Os JSONs do WebPageTest nunca saem do navegador.
  • Variações abaixo de 5% viram “empate técnico”, nunca narrativa de ganho.
  • Se a IA falhar ou inventar, entra uma narrativa determinística.
  • Roda numa Edge Function da Azion com Qwen3 e exporta PDF em folhas A4.

JavaScript, Azion AI Inference, WebPageTest

Compat Validator

JavaScript

Diz se as dependências de um projeto rodam no Azion Runtime e dá um veredito de deploy. Regras determinísticas primeiro; a IA entra só no que não está catalogado, sempre marcada como sugestão.

  • Aceita package.json, lista solta ou uma linha de npm install colada.
  • devDependencies e ferramentas de build nunca bloqueiam o deploy.
  • Pacotes desconhecidos vão para a IA em lotes, com concorrência.
  • UI e API servidas por uma única Edge Function.

JavaScript, Azion Edge Functions, AI Inference

Rule Builder

Python

Monta uma regra de Edge Firewall uma vez e aplica em todos os firewalls da conta, com simulação antes. Fala com as APIs v3 e v4 sem que o resto do programa saiba qual está em uso.

  • Só Python 3.8+ e a biblioteca padrão, sem dependências.
  • Simula o plano antes de aplicar na frota.
  • A mesma regra dá NOOP nas duas versões da API.
  • API falsa embutida para testar sem tocar na conta.

Python, Azion API v3 e v4
